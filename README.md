# The New York Times Clone

A pixel-perfect, responsive replica of **The New York Times** digital front page, built with modern Next.js (App Router), TypeScript, and Tailwind CSS.

## Features

- **Pixel-Perfect NYT Front Page**: Full editorial layout with classic typography (NYT Cheltenham Serif & Franklin), accurate dividers, multi-column editorial hierarchy, and authentic section modules.
- **Dynamic Article Routing (`/article/[slug]`)**: Every headline and photo across the homepage connects to its dedicated, fully formatted article reading experience with audio listen bar, bylines, share controls, right sidebar with Trending stories, and comments.
- **Dedicated Writer Portfolios (`/by/[slug]`)**: Dynamic author pages for featured NYT journalists (Michael Crowley, Maggie Haberman, Siobhán O’Grady) with custom author bios, latest reporting, and category pagination.
- **Interactive Mega Menus & Navigation**: Authentic NYT masthead, sticky category navbar, breaking news banners, date ticker, and rich dropdowns.
- **Comprehensive Sections**:
  - Main Editorial Hero & Analysis
  - Right Sidebar with Rare Science Books feature & Opinion Columnists
  - Election 2026 Midterms
  - World & International Reports
  - The Athletic Sports Hub
  - Culture, Arts, TV & Movies
  - Wirecutter Product Reviews
  - Well & Living Columns
  - Games (Wordle, Connections, Spelling Bee, Crosswords)

## Tech Stack

- **Framework**: Next.js 16 (Turbopack, App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Design Tokens**: NYT Cheltenham, Franklin, Karnak, and custom newspaper styling

## Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
